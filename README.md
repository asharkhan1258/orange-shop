
# GN Service — Orange-Only Bootstrap Website

This is a static HTML/CSS/Bootstrap website concept inspired by the page organization and clean produce-industry presentation of SunPacific.com, but with original copy, original/local orange artwork and a single-product focus on oranges.

## Tech
- HTML5
- Bootstrap 5.3.3 via CDN
- Bootstrap Icons via CDN
- Custom CSS: assets/css/style.css
- Custom JS: assets/js/main.js
- Local orange-only images/illustrations: assets/img/

## Important before publishing
1. Connect the contact form to your actual PHP/backend/email/CRM service.
2. Replace or add official phone, email and address if desired.
3. Have the legal pages reviewed for your jurisdiction and actual business terms.
4. If you want a fully offline build, download Bootstrap and Bootstrap Icons locally and replace the CDN links.
